still-ui is a VPN panel for Xray-core, built from 3x-ui for servers that run for months on 2 GB of RAM, with real people on mobile networks.

bash <(curl -Ls https://github.com/Dv2Corn/still-ui/releases/latest/download/install.sh)

Linux amd64 / arm64 · runs as root · prints the panel address, login and password at the end

The things that used to hurt. Fixed.

Everything 3x-ui does still works: the same protocols, the same interface, the same database. still-ui changes what breaks on a small server after a few months.

Clients keep their settings

Updating a client through the API with only some fields no longer disables it and wipes its limits, Telegram ID and renewal settings.

Restarting the panel drops nobody

Xray runs as its own sandboxed service. Update or restart the panel and Xray clients stay connected.

The panel stays small

A memory cap from the installer and pooled AmneziaWG buffers: a runaway panel restarts instead of pushing the server into swap.

iOS fingerprint and sing-box work again

A reproducible Xray build with a one-hunk REALITY patch accepts the short ios ClientHello that mobile networks let through.

Certificates renew without you

The panel checks what each inbound really serves and restarts only Xray, only when a renewed certificate was not picked up.

Local sites open directly

One setting: banks and government portals of your country open without the VPN, everything else goes through it. In every subscription format.

Already on 3x-ui? One command.

The installer finds your 3x-ui database, moves inbounds, clients and subscriptions over and checks they are the same. Users keep their links. Another command brings 3x-ui back.

Built to be checked.

You run this on your server with root. You should not have to take our word for anything.

Attested builds

Every release archive is built by GitHub Actions and carries a build attestation. gh attestation verify shows where it came from.

Checked installer

Each release publishes its own install.sh in SHA256SUMS. The installer refuses an archive whose checksum is missing or wrong.

A journal you can verify

Admin actions go to a hash-chained audit log, and the panel can check that no entry was changed or removed.
