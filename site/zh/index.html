still-ui 是基于 3x-ui 的 Xray-core VPN 面板，专为在 2 GB 内存上连续运行数月、用户使用移动网络的服务器而打造。

bash <(curl -Ls https://github.com/Dv2Corn/still-ui/releases/latest/download/install.sh)

Linux amd64 / arm64 · 以 root 运行 · 结束时显示面板地址、用户名和密码

曾经的痛点，已经修好。

3x-ui 的一切照常可用：相同的协议、相同的界面、相同的数据库。still-ui 修复的是小服务器运行几个月后才会出现的问题。

客户端保留设置

通过 API 只更新部分字段时，客户端不再被禁用，限额、Telegram ID 和续期设置也不再被清空。

重启面板不掉线

Xray 作为独立的沙箱服务运行。更新或重启面板，Xray 客户端保持连接。

面板保持轻量

安装程序设置内存上限，AmneziaWG 缓冲区复用：失控的面板会被重启，而不是把服务器拖进 swap。

iOS 指纹和 sing-box 重新可用

可复现的 Xray 构建加上一处 REALITY 补丁，重新接受移动网络放行的短 ios ClientHello。

证书自动续期生效

面板检查每个入站实际提供的证书，仅在新证书未被加载时才只重启 Xray。

本地网站直连

一个设置：本国的银行和政府网站不走 VPN，其余流量走 VPN。适用于所有订阅格式。

已经在用 3x-ui？一条命令。

安装程序会找到 3x-ui 数据库，迁移入站、客户端和订阅，并检查结果一致。用户的链接保持不变。另一条命令可以切回 3x-ui。

bash <(curl -Ls https://github.com/Dv2Corn/still-ui/releases/latest/download/install.sh) migrate

可证明的构建

每个发布包都由 GitHub Actions 构建并附带构建证明。gh attestation verify 可以查看来源。

可校验的安装程序

每个版本都在 SHA256SUMS 中发布自己的 install.sh。校验和缺失或不符的包会被拒绝。

可验证的日志

管理员操作写入哈希链审计日志，面板可以检查是否有记录被修改或删除。
